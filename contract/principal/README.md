# Principal contract

Who is calling an application, as identity states it on every channel. Each language's adapter pins
a version of this directory and is held to its conformance vectors.

- `principal.schema.json`: the Principal an adapter produces.
- `mapping.json`: each field's claim and plain header, and for each channel (the signed Gate
  header, JWT access tokens, introspection) how to read it and when to refuse it.
- `vectors/jwks.json`: the Issuer's published key the vectors are signed with.
- `vectors/signed-header/*.json`: a request the Gate answered, the Client reading it and the time
  it reads it at, and the Principal or the refusal every adapter must conclude.
- `vectors/access-token/*.json`: a JWT access token identity issued, the Client reading it and the
  time it reads it at, and the Principal or the refusal.
- `vectors/introspection/*.json`: identity's introspection answer to a Client's check of a Personal
  Token or a Connected App's token, and the Principal or the refusal.

## Pinning a version

Each release is tagged `contract/principal/vX.Y.Z`.

- Go: `go get github.com/JorisJonkers-dev/identity/contract/principal@vX.Y.Z`, then read `principal.Files`.
- Other languages: fetch the files from
  `https://raw.githubusercontent.com/JorisJonkers-dev/identity/contract/principal/vX.Y.Z/contract/principal/`
  and pin their checksums.

A minor version only adds optional fields, which a reader ignores when it does not know them. A
major version is served beside the previous one for one window, and a reader refuses a major it
does not know.

Version 1.1 added the access-token and introspection channels; the Principal itself is unchanged.

The vectors are generated by identity's own signing and claim code. Change them only through
`go test ./internal/gate/adapters/principal -run TestTheCommittedVectorsAreTheOnesIdentityStates -update`.
