# Schema changes run through liquibase-runner, not the template's goose

The template this repository came from applies embedded goose migrations at startup. identity replaces that before its first schema, per [workspace ADR-0021](https://github.com/JorisJonkers-dev/workspace/blob/main/docs/decisions/ADR-0021-liquibase-runner-is-the-one-migration-path.md): a separate `identity-migration` image built `FROM liquibase-runner` carries the YAML changelog and alone holds the owner role, the service's database user may read and write rows but not change the schema, `sqlc` reads a `db/schema.sql` generated by `task gen:schema`, and tests copy a once-migrated template database. identity's changelog starts fresh; auth-api's Flyway history is not carried over, and its data arrives through the one-off import ([0006](0006-legacy-auth-is-a-client-during-migration.md)).

## Lint and timeouts (identity#10)

Moving off goose dropped `squawk`, which refused long locks and destructive statements, and nothing set `lock_timeout` or `statement_timeout`. Both now come from the runner, not from identity, so every service's migrations get them ([deploy-kit ADR 0108](https://github.com/JorisJonkers-dev/deploy-kit/blob/main/docs/adr/model/0108-the-runner-lints-a-release-and-bounds-its-locks.md)):

- **The lint is a fourth migration-safety obligation.** `runner ci lint` renders each changeset of a release with Liquibase `update-sql` against the serving schema and lints it with `squawk`. The runner's own tests hold the fixture that proves it fails.
- **Exceptions are written in the changeset.** A changeset that means to drop or rewrite names each rule in its `comment`: `lint-allow ban-drop-column: <why>`.
- **Every migration gives up instead of stalling.** The runner connects with `lock_timeout` 5s and `statement_timeout` 15min. A changeset that needs longer sets its own.

identity runs the 0.2.0 runner image in `Dockerfile.migration`, `compose.yaml` and the tests' template database, so every migration, in CI and in the cluster, gets both timeouts.
